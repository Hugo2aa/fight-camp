# Fight Camp

App personnelle de discipline, nutrition et sèche pour le MMA et la boxe.

- Checklist quotidienne, série de jours, citations de combattants
- Nutrition : table Ciqual 2025 (Anses), photo des plats analysée par Claude, Chef qui propose des plats
- Programme du coach importé depuis un PDF ou des photos, conseils de charge
- Suivi du poids, paliers, photos de progression
- Routines de souplesse guidées (high kick, hanches)
- Fonds d'écran générés

Hébergée sur GitHub Pages, données et photos sur Supabase, IA via une fonction Supabase qui garde la clé API côté serveur.

Données nutritionnelles : Table de composition nutritionnelle Ciqual 2025, Anses.
